# 📊 可视化仪表盘使用指南

## 功能概述

可视化仪表盘提供了Web界面来查看股票分析结果,替代或补充邮件推送功能。

### 主要功能

1. **决策仪表盘** - 实时展示最新的分析结果
   - 统计信息: 买入/持有/卖出数量、平均评分
   - 股票卡片: 每只股票的详细分析信息
   - 核心结论: 一句话决策建议
   - 操作点位: 买入价、止损位、目标位
   - 检查清单: 各项条件的检查结果

2. **历史记录** - 查看历史分析数据
   - 按日期查看历史分析
   - 按股票代码查看单只股票的历史

3. **自动刷新** - 每30秒自动更新数据

## 启动方式

### 方式一: 命令行启动

```bash
python main.py --webui
```

### 方式二: 配置文件启用

在 `.env` 文件中设置:

```env
WEBUI_ENABLED=true
WEBUI_HOST=127.0.0.1
WEBUI_PORT=8000
```

然后正常运行:

```bash
python main.py
```

## 访问地址

启动后,可以通过以下地址访问:

- **配置管理页面**: `http://127.0.0.1:8000` (编辑股票列表)
- **可视化仪表盘**: `http://127.0.0.1:8001` (查看分析结果)

## 安装依赖

如果遇到导入错误,请安装Flask相关依赖:

```bash
pip install flask flask-cors
```

或者安装所有依赖:

```bash
pip install -r requirements.txt
```

## 数据存储

分析结果会自动保存到数据库(`data/stock_analysis.db`),包括:

- 股票代码和名称
- 分析日期
- 综合评分和操作建议
- 完整的决策仪表盘数据
- 报告内容(Markdown格式)

## API接口

可视化服务提供了以下API接口:

### 获取最新分析结果

```
GET /api/latest
```

返回今日的分析结果,如果没有今日数据则返回最新的分析结果。

### 获取指定股票的分析

```
GET /api/stock/<code>
```

例如: `/api/stock/600519`

### 获取历史记录

```
GET /api/history?days=7
```

返回最近N天的分析记录(默认7天)。

## 界面说明

### 统计卡片

- 🟢 **建议买入/加仓**: 评分较高,建议买入的股票数量
- 🟡 **建议持有/观望**: 评分中等,建议持有的股票数量
- 🔴 **建议减仓/卖出**: 评分较低,建议卖出的股票数量
- 📈 **平均评分**: 所有股票的平均评分

### 股票卡片

每个股票卡片显示:

1. **股票信息**: 名称、代码、操作建议
2. **综合评分**: 0-100分的评分(颜色编码)
3. **趋势预测**: 看多/看空/震荡等
4. **核心结论**: 一句话决策建议
5. **操作点位**: 买入价、止损位、目标位
6. **检查清单**: 各项条件的检查结果(✅/⚠️/❌)

## 注意事项

1. **数据更新**: 分析结果在每次运行分析后自动保存到数据库
2. **端口冲突**: 如果8000或8001端口被占用,请修改配置
3. **数据库**: 首次运行会自动创建数据库和表结构
4. **性能**: 建议在本地或内网使用,生产环境请配置适当的访问控制

## 故障排查

### 无法访问仪表盘

1. 检查是否已安装Flask: `pip list | grep flask`
2. 检查端口是否被占用: `lsof -i :8001`
3. 查看日志文件了解详细错误信息

### 没有数据显示

1. 确保已运行过分析: `python main.py`
2. 检查数据库文件是否存在: `ls -l data/stock_analysis.db`
3. 查看数据库中的记录: 可以使用SQLite工具查看

### 样式显示异常

1. 清除浏览器缓存
2. 检查浏览器控制台是否有JavaScript错误
3. 确保网络连接正常(某些资源可能需要网络加载)
